# Token artwork, source references and bundled assets

> Current audit target: [5.0.2 (104) prerelease](RELEASE-5.0.2-104.md). Earlier results below retain their original tested versions and commits; they are not retroactively tests of build 104.

The public app calls the artwork decoder for downloaded data and data read from its disk cache (ArtworkLoader.swift, lines 192 and 266 at the current pin). ArtworkURLTransport uses an ephemeral session without cookies or credential storage, validates both request and redirect targets, checks HTTP results, and enforces an 8 MiB limit while reading the stream. The SVG parser imposes tighter byte, XML nesting, node-count, expanded-size, and path-depth limits. Checks on byte count alone cannot bound how many shapes a reference graph creates. Hostname policy, DNS resolution, alternative raster decoder behavior, CSS parsing, disk races and package-wide cancellation are outside the verified scope of this checkpoint.

**Dynamic references.** At SwiftDraw 0.29.0 the SwiftDraw library depends on SwiftDrawDOM. The manifest declares no further external Swift packages. DOM.Use.swift first consults the definitions dictionary and otherwise walks root children in order. LayerTree.Builder dispatches use elements to makeUseLayerContents, which selects the referenced graphics element and recursively builds it. These paths establish why a validator that silently overwrites duplicate IDs can check the wrong graph. See [OW-2026-030](../findings/OW-2026-030.md) for the two baseline failures and repaired controls. The provider controls the image, not a wallet key. Rendering a single synthetic document crashed the original host decoder. No signing or balance mutation is demonstrated by that crash.

**Dependency inventory.** The pinned package lock and the actual checked-out Git revision agree. [SwiftDraw ledger](../scope/upstream-swiftdraw.json) lists every upstream blob and its hash, independently of the vendored Reown and Wallet Core inventories. Package.swift and the complete DOM.Use.swift were read for this scope. The large layer builder files retain partial dispositions for the traced methods. All other entries remain outstanding, including code elsewhere that interprets styles, transforms and drawing commands. The inventory records source membership in the two library targets separately from test data, examples and CLI paths.

**Bundled artwork.** The separate static-asset pass covers 714 tracked files in OathApp/Assets.xcassets. It parses all 304 manifests, validates their paths within their asset sets, checks all 386 distinct declared files exist, and decodes all 408 single-frame PNG/JPEG images at their declared dimensions using ImageIO. The two PDF files are hashed and checked for their manifest references. Their internal content was not audited. Twenty-four JPEGs have no filename reference in these manifests. The report retains them without treating absence from the manifests as proof of exclusion from every possible build.

The ReceiveAssets table supplies 268 unique source IDs in 38 network groups. Every ID has the expected network prefix and all 196 named image sets resolve, with no unreferenced set. The receive catalog and token views use network plus asset reference to look up a logo. Assets can intentionally share artwork. Structural checks do not establish issuer authenticity, unique economic identity after every network-specific normalization, or that two similar icons can be distinguished. Network, token and keypad assets therefore retain partial dispositions. The specifically enumerated launcher icons and their Settings previews are classified as cosmetic non-security content after checking the selection enum, asset sets and Xcode icon build settings. No image is marked manually reviewed based on a decode.

Reproduce the resource pass with `python3 scripts/bundled-artwork.py <clean-app> --output .work/bundled`. Reproduce dependency hashes with `python3 scripts/swiftdraw-inventory.py <pinned-SwiftDraw-checkout> --output .work/swiftdraw.json`. Machine-readable [resource evidence](../evidence/svg-graph/oath-svg-depth-evidence/resources/asset-coverage.json) includes file hashes, dimensions, declared owners and unreferenced resources.
