# OW-2026-021 — Session timers and storage callbacks could outlive their owners

Severity: **low**, SDK availability and resource lifetime. No remote Oath exploit,
secret disclosure or fund loss has been demonstrated.

## Affected source

At regression baseline `5522b5ff7c30279151ee2a4d88b6d9a8c0fd400e`:

- [ProposalExpiryWatcher.swift:25–29](https://github.com/devdasx/oath-wallet/blob/5522b5ff7c30279151ee2a4d88b6d9a8c0fd400e/Vendor/Reown/Sources/WalletConnectSign/Engine/Common/ProposalExpiryWatcher.swift#L25-L29)
- [RequestsExpiryWatcher.swift:27–31](https://github.com/devdasx/oath-wallet/blob/5522b5ff7c30279151ee2a4d88b6d9a8c0fd400e/Vendor/Reown/Sources/WalletConnectSign/Engine/Common/RequestsExpiryWatcher.swift#L27-L31)
- [SessionStorage.swift:25–30](https://github.com/devdasx/oath-wallet/blob/5522b5ff7c30279151ee2a4d88b6d9a8c0fd400e/Vendor/Reown/Sources/WalletConnectSign/Storage/SessionStorage.swift#L25-L30)

The repeating timers and callbacks captured owners as unowned even though the
scheduler or underlying store could remain alive after owner release. Four
isolated cases abort with an unowned-reference access. Repeated watcher setup
also leaves the earlier timer registered: both repeat every three seconds.
Expected behavior is one active timer while a watcher exists, no callback into
a released wrapper, and preserved notification delivery to a live/new wrapper.

## Fix and retest

Fix commit: `d13c1979398ab3dc51d9af18f5bf23821e18262f`.

[PR 31](https://github.com/devdasx/oath-wallet/pull/31) merged as `413b70fbeca15b24e572f7c7f993a62d11a8184e`.
Application source matches the tested pin; 97 concurrent website-only
differences are recorded in [merge evidence](../evidence/watcher-lifetime-merge-identity.json).

Timers invalidate before replacement and during teardown; timer and storage
closures capture owners weakly. Replacement wrapper callbacks are not cleared
by an older wrapper's destruction.

The same ten-case production fixture gives four crashes, two duplicate-timer
assertions and four passing controls before; all ten pass after. The SDK suite
passes 157 cases with one explicit skip; diagnostics pass 118 with two skips.
Original failures and the fixture's initial compile error remain in the
[evidence](../evidence/watcher-lifetime/manifest.json).

[Review scope, reproduction command and open areas](../review/WATCHER-LIFETIME-REVIEW.md)
include the actual factory ownership trace. Ordinary singleton retention limits
the demonstrated app reachability. This is a source repair, not a verified
App Store update. No simulator or physical-device check occurred.
