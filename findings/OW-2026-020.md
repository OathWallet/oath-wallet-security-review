# OW-2026-020 — Outgoing requests lost relay lifetime and bypassed service expiry checks

> Current audit target: [5.0.2 (104) prerelease](../review/RELEASE-5.0.2-104.md). Earlier results below retain their original tested versions and commits; they are not retroactively tests of build 104.

Severity: **low**, SDK transport correctness. No incoming Oath signing bypass,
secret exposure or fund loss has been demonstrated.

## Affected behavior

[Baseline SessionRequester](https://github.com/devdasx/oath-wallet/blob/a90d99005f3b8476178a968ba1016c0347e0328e/Vendor/Reown/Sources/WalletConnectSign/LinkAndRelayDispatchers/SessionReq.swift)
calculated the remaining TTL and constructed a protocol method with that TTL,
then passed a new default method to networking. A one-hour request received a
300-second relay lifetime; an elapsed request with a minute remaining also
received 300 seconds. NetworkingInteractor forwards that configuration to the
relay publisher. These tests establish the supplied value, not observed server
retention or user fund loss.

The same function returned through a matching wallet service before checking
expiry. An already-expired request or a decoded/mutated `UInt64.max` expiry
could therefore reach that service. The controlled fixture uses only synthetic
requests and spies; it does not contact any service.

## Repair and evidence

Regression-only commit: `a90d99005f3b8476178a968ba1016c0347e0328e`.
Fix: `05f1f349938c3281810241513bae8beceab35ffd`.
[PR 30](https://github.com/devdasx/oath-wallet/pull/30) merged as `5ff8506b87d8ac773d30cc8f38a4c3aa939cc99c`; application source matches the tested commit.

Validation now happens after the existing session/permission guards and before
either transport is selected. The relay receives the validated protocol-method
instance. Valid request payloads and routing are unchanged.

Identical eleven-case fixture: **six expected assertion failures across four
cases before, seven passing controls; all eleven pass after**. Full SDK suite:
147 passed/one skipped. Diagnostics: 118 passed/two skipped. Source/secret checks,
diagnostics coverage, 130 audit helper tests and generic unsigned iOS Release
compilation pass. Original failures and a test-import setup error remain in
the [evidence manifest](../evidence/request-lifetime/manifest.json).

The SDK's public request API is for outgoing dApp requests. Oath's inspected
service responds to incoming requests; no outgoing invocation was found there.
See [caller trace, test boundaries and unresolved lifecycle work](../review/REQUEST-LIFETIME-REVIEW.md).
This is a source fix, not a verified App Store release. No simulator, physical
device, live relay or App Store operation occurred.
