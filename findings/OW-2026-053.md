# OW-2026-053 · Malformed ENS results can trap the bundled ABI decoder

> Current audit target: [5.0.2 (104) prerelease](../review/RELEASE-5.0.2-104.md). Earlier results below retain their original tested versions and commits; they are not retroactively tests of build 104.

## Severity and reachability

Severity is low for Oath's current application. The bundled WalletConnectSigner ENS decoder traps or accepts malformed provider responses in direct host tests. The source search found no call from Oath's application into this ENS resolver. The defect is confirmed in compiled dependency code. Exposure through a current user-facing Oath flow remains unproven.

Affected source is `c7acd23bb139864a40273f405d18b479589d2b20`. ContractDecoder.int force-unwraps an unrepresentable or nonnumeric word. ContractDecoder.dynamicBytes multiplies offsets and lengths before proving they fit. The address and bytes paths also fail to validate hexadecimal contents and ABI padding. [Original decoder](https://github.com/devdasx/oath-wallet/blob/c7acd23bb139864a40273f405d18b479589d2b20/Vendor/Reown/Sources/WalletConnectSigner/Ethereum/ContractCall/ContractDecoder.swift#L5-L38).

## Evidence and expected behavior

The exact release replay produces seven process traps and four failing methods among sixteen focused methods. The repaired source passes all sixteen. Invalid provider input must throw a decoding error. Valid addresses, names and dynamic bytes must retain their original interpretation. All fixtures use synthetic data and the per-case processes deny network access. [Before/after results](../evidence/5.0.1-build103/ens-contract-decoding/result.json) · [Review, reachability and reproduction details](../review/ENS-CONTRACT-DECODING.md).

The repair validates ASCII hexadecimal bytes, high address padding, offset alignment, checked integer conversion, length bounds and zero padding before decoding. The fix is in public source commit `7c6209a999b62003e0c4d2f16aec7810a4e5d56c`. The reproducible harness has a separate isolated-build-cache follow-up at `a6b08a0890564489a12a0cb13987d9b2f885dd1e`. [PR 66](https://github.com/devdasx/oath-wallet/pull/66) was merged at `cd63782a33f35361f9ee4cbc6a05330e1b919fc1`. Its tree matches the tested candidate. [Build and validation receipt](../evidence/5.0.1-build103/ens-contract-decoding/validation.json).

This change follows the build 103 release tag. Availability in the App Store has not been verified.
