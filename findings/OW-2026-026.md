# OW-2026-026 — Session responses were not bound to the pending remote request

> Current audit target: [5.0.2 (104) prerelease](../review/RELEASE-5.0.2-104.md). Earlier results below retain their original tested versions and commits; they are not retroactively tests of build 104.

Severity: **low, SDK API integrity and potential misrouting**. A wrong-session
caller can route a result to another peer and consume the wrong pending entry;
Oath's inspected callers retain the original topic, and no remote signing bypass
or fund loss was established.

## Source and reproduction

Regression baseline `42846f9f9b9ff66ff8407700aa77539e70f963c5`:
- [Relay SessionResponder:35](https://github.com/devdasx/oath-wallet/blob/42846f9f9b9ff66ff8407700aa77539e70f963c5/Vendor/Reown/Sources/WalletConnectSign/Engine/Wallet/SessionResponder.swift#L35) checks session existence without pending-topic equality.
- [LinkSessionResponder:31](https://github.com/devdasx/oath-wallet/blob/42846f9f9b9ff66ff8407700aa77539e70f963c5/Vendor/Reown/Sources/WalletConnectSign/LinkAndRelayDispatchers/LinkSessionResponder.swift#L31) checks the supplied session and looks up expiry by ID.
- [HistoryService:31](https://github.com/devdasx/oath-wallet/blob/42846f9f9b9ff66ff8407700aa77539e70f963c5/Vendor/Reown/Sources/WalletConnectSign/Services/HistoryService.swift#L31) maps any matching parameter shape, without checking origin or outer method.

Expected: reject mismatched session, local-origin and non-session-method records
before response or expiry-error side effects. Observed before: 18 assertions
across eight failed cases; four valid/expiry controls pass. All 12 pass after.
Link tests decrypt the wrongly routed response and observe history consumption;
relay tests record endpoint invocation, not actual network delivery.

Fix: `8508d02deaf965dbe6f46b3c0ca637074234e5da`. Remote origin and wc_sessionRequest method are required by the
response getter; both responders compare topics and check expiry on the same
captured request. Storage compatibility is unchanged. See the
[scope and reproduction](../review/SESSION-RESPONSE-ROUTING.md) and
[hashed evidence](../evidence/response-routing/manifest.json).

Remaining generic transport and history concurrency concerns are explicitly
unresolved. SDK 229 passes/one skip, diagnostics 118/two skips and unsigned
iOS Release compile pass. Source fixes are not proof of App Store availability.
