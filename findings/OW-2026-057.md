# OW-2026-057 · Malformed protocol-key hex is silently coerced

Severity is low: malformed protocol-key admission and delayed rejection were reproduced. The tests establish no wallet-key disclosure, forgery or consent bypass. Source tracing connects the affected KMS method to session approval; a malicious session was not exercised through Oath's UI.

The legacy hex decoder appends the high nibble when a low nibble is invalid or absent, and permits lossy text conversion. Several 63/64-character malformed strings therefore become 32-byte keys accepted by CryptoKit wrappers. The symmetric-key wrapper also accepts arbitrary byte lengths. [Original decoder](https://github.com/devdasx/oath-wallet/blob/c7acd23bb139864a40273f405d18b479589d2b20/Vendor/Reown/Sources/WalletConnectUtils/Extensions/Data%2Butils.swift#L26-L57) · [Original symmetric wrapper](https://github.com/devdasx/oath-wallet/blob/c7acd23bb139864a40273f405d18b479589d2b20/Vendor/Reown/Sources/WalletConnectKMS/Crypto/SymmetricKey.swift#L11-L43).

A synthetic key-agreement test supplies the X25519 base point with an invalid final hex character. The original KMS silently converts it and completes agreement. The repair rejects the encoding before agreement. Other cases test private/public key constructors, symmetric-key lengths, every invalid ASCII low nibble and persistence of valid agreement records.

The repair adds a throwing ASCII hex decoder and uses it in key constructors. The legacy Data(hex:) interface returns empty data for malformed input instead of partial/coerced bytes. Symmetric key constructors require 32 bytes or 256 bits. The public CryptoKit-key wrapper now throws; HKDF propagation and callers were updated. Valid stored key bytes and the 64-byte agreement record format are unchanged.

On exact build 103, eleven methods fail with 153 assertions and four controls pass. All fifteen pass after repair. The valid X25519/HKDF output also matches an independently generated Node/OpenSSL result. The regression calls the production KMS directly and CryptoKit performs the agreement.
