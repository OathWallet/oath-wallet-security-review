# OW-2026-002 — Missing aezeed bridge build source

Classification: **Assurance/provenance gap**, not a demonstrated cryptographic flaw.

The baseline `Packages/OathAezeed/README.md` instructs builders to run
`Tools/AezeedBridge/build.sh`, but the pinned public Git tree contains no such
directory. The app instead links bundled static archives. Hashing an archive
does not show that it was built from the documented LND implementation.

Required repair: publish the bridge, headers, pinned Go dependencies and fixture
generators; build them in isolation and compare generated public vectors with
the checked-in fixtures. Record archive reproducibility separately. Do not
claim historical binary equivalence merely because a fresh build succeeds.

Until source and validation are published, upstream implementation coverage and
source-to-binary equivalence remain unproven.

The bridge source, pinned Go modules, generators and regression tests are now
published at `ae5a35cec58f51bcfd6de3cd55950b47fa055a51`. Go race tests and vet
pass, and regenerated public seed fixtures equal the checked-in fixtures.
However, all three reconstructed archive hashes differ from their historical
counterparts. The historical binaries were retained unchanged. Source omission
is repaired; historical binary equivalence remains unresolved.
