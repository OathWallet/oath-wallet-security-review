# OW-2026-030 — Untrusted token artwork bypassed graph checks and crashed the renderer

**Severity: medium, application availability.** A token logo obtained from provider metadata or cache enters the public artwork decoder. A small synthetic document terminated a host process calling that decoder. Display frequency, per-provider acceptance, device behavior and recurrence after relaunch have not been measured. No access to wallet secrets or unauthorized signing was demonstrated.

## Cause

The [original validator](https://github.com/devdasx/oath-wallet/blob/34ba87a3e0b2beb27bd1acdb618e480f5faefb9d/Packages/OathTokenImages/Sources/OathTokenImages/ArtworkImage.swift#L100) overwrote an earlier ID with the last matching element. SwiftDraw [selects a definition or the first matching child](https://github.com/swhitty/SwiftDraw/blob/82699f4bdf2f075793cfa0d392eb27c59b41a3fe/DOM/Sources/DOM.Use.swift#L48) and [recursively builds the referenced layer](https://github.com/swhitty/SwiftDraw/blob/82699f4bdf2f075793cfa0d392eb27c59b41a3fe/SwiftDraw/Sources/LayerTree/LayerTree.Builder.Layer.swift#L43). With two same-ID root children, validation followed a rectangle while the renderer followed a self-reference. The controlled case exited with signal 11.

The validator also cached each subtree's expanded node count without its height. Reusing an already checked leaf-first chain allowed the same subtree to be entered too deeply. Reversing the definitions restored rejection. A small finite case reproduced the depth bypass independently of the crashing case.

## Repair and evidence

[Repaired decoder](https://github.com/devdasx/oath-wallet/blob/1dbe6cbabb7397ad86be917e034fb88884fbca8d/Packages/OathTokenImages/Sources/OathTokenImages/ArtworkImage.swift#L110). Each document ID must be unique. Memoized entries retain their expanded size and height; the current depth plus cached height must fit the 64-node path budget. The expanded 20,000-node ceiling remains cumulative across reference edges. An image recognized as SVG by ImageIO goes through the SVG policy, rather than the generic raster branch. The test does not establish which image types every OS release recognizes.

[Identical five-case fixture](https://github.com/devdasx/oath-wallet/blob/34ba87a3e0b2beb27bd1acdb618e480f5faefb9d/Packages/OathTokenImages/Tests/OathTokenImagesTests/ArtworkReferenceDepthTests.swift). Baseline: one signal 11, one incorrect acceptance, three passing controls. Fixed: five passes. Exact-limit drawings in both orders and two siblings using one unique definition still decode. The invalid cases must reach the designated safety rejection after the repair.

Run `python3 scripts/svg-reference-graph.py <clean-app> --scratch .work/svg-build --output .work/svg-results`. The dependency resolution/build may retrieve the pinned public package. Each XCTest runs in a separate network-denied host process with a timeout and core dumps disabled. A signal from a different case, a compiler error or a different assertion cannot satisfy the expected baseline.
