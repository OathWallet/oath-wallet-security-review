# OW-2026-037 — A rejected edit could leave the previous recovery phrase eligible for import

Low severity, local input integrity. The previous Electrum or aezeed phrase remained in the editor after an oversized input was rejected. Its detector still selected it, allowing a later deliberate tap to start importing the previous wallet. Both synthetic cases reproduced this state. The format decision now gates both routes on usable, committed input.
