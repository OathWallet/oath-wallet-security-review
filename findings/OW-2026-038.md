# OW-2026-038 — Public text could be selected as an Electrum wallet during scanning or paste

Moderate severity, conditional wallet substitution. Three synthetic public payloads matched the Electrum version prefix and were accepted by the dedicated recovery scanner. If the user proceeded and later funded a wallet derived from public text, others with that text could derive the same keys. No funds were involved in testing. The correction separates scan recognition from deliberate Electrum parsing. The scanner preserves the prior draft on rejection. A second probe reproduced all three cases through manual paste after the scanner repair. The subsequent repair requires an explicit Electrum selection for unusual manual input and preserves legacy hexadecimal input.
