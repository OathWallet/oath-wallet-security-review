# OW-2026-024 — Incoming links bypassed session encryption and response-topic binding

Severity: **medium, SDK message integrity and availability**. Oath advertises
Link Mode disabled and has no inspected app caller of the dispatcher, so an
installed-app authorization bypass or fund loss is not established.

## Affected source and reproduction

At regression-only baseline `18b1033433143f30eeedf5b29e1ab16ea4e12f88`:

- [LinkEnvelopesDispatcher.swift:189](https://github.com/devdasx/oath-wallet/blob/18b1033433143f30eeedf5b29e1ab16ea4e12f88/Vendor/Reown/Sources/WalletConnectSign/Auth/Link/LinkEnvelopesDispatcher.swift#L189)
  decodes both encrypted and plaintext frames without restricting plaintext to
  initial authentication.
- [LinkEnvelopesDispatcher.swift:214](https://github.com/devdasx/oath-wallet/blob/18b1033433143f30eeedf5b29e1ab16ea4e12f88/Vendor/Reown/Sources/WalletConnectSign/Auth/Link/LinkEnvelopesDispatcher.swift#L214)
  resolves responses by RPC ID without expected topic or local-origin checks.

A sender with only topic B's key and a known pending RPC ID can dispatch a
response for A and consume A's pending record. A keyless sender can dispatch
plaintext session messages and responses. Both success/error and remote-origin
cases are reproduced with synthetic memory-only fixtures and no networking.
This proves subscriber delivery/history mutation; it does not prove unknown-ID
discovery, URL ownership bypass, real peer exploitation, automatic signing or theft.

## Repair and result

Fix commit: `f2019f3e752ee3fb1b57d7259abb8721779f0cc8`. [PR 34](https://github.com/devdasx/oath-wallet/pull/34).
Merged as `888fa6f53e117bc8b2591c8a6643426d58fa2462`; [application identity](../evidence/link-boundary-merge-identity.json) matches the tested pin.
Only initial `wc_sessionAuthenticate` requests may be plaintext. Incoming
responses must be encrypted and match a locally originated request's expected
response topic before history is deleted. Separate authentication response topics
remain supported. Outgoing acknowledgement and wallet storage formats are unchanged.

Same 16 cases: 18 assertions across eight failing cases and eight passing
controls before; all 16 pass after. The production serializer and cryptography
run unchanged. Full SDK: 201 passes/one skip; diagnostics: 118 passes/two skips.
Read the [review and exact limits](../review/LINK-ENVELOPE-BOUNDARIES.md) and
[hashed before/after evidence](../evidence/link-boundary/manifest.json).
Public-source repair does not establish availability in an App Store build.
