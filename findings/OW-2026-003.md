# OW-2026-003 — omitted public signing-policy adapters

> Current audit target: [5.0.2 (104) prerelease](../review/RELEASE-5.0.2-104.md). Earlier results below retain their original tested versions and commits; they are not retroactively tests of build 104.

Severity: **informational / coverage defect**. No demonstrated fund-loss exploit.
Baseline affected: 4.1.15 (100), `c7cdbde5e9f136b595500e92fbc904b107dcd8ee`.

`Packages/OathAnkr/Sources/OathAnkr/PublicSigningEVM.swift:6–19` omits Filecoin,
Sei, 0G and IoTeX even though the public EVM network enum supports them.
`PublicSigningAuthority.fetch` consequently returns `notDiscoverable` without
reading these accounts. This does not return a false `checked` success, and no
direct application caller of this API was found. The endpoint dictionary is also
reused by stablecoin checks. Do not present this as proof of theft or bypass.

Expected behavior: supported mainnet accounts use their adapter, verify the
provider's chain ID before account reads, and preserve unavailable/unknown states.

## Reproduction and repair

The preexisting `testAllCurrentEVMMainnetsHaveAnAdapter` fails on the original
code. Added `testAdditionalEVMAdaptersValidateChainBeforeReadingAccountCode`
uses a synthetic public address and a recording transport. For each network it
checks empty code, delegated code, endpoint selection, RPC ordering, and rejection
of a provider returning Ethereum's chain ID before any block/account-code read.
No live provider, key or transaction is used.

With the new test applied but original production code retained, the 15-test
suite reports 37 assertion failures. Adding the four existing public endpoints
already used by `IndexedEVMClient` passes the same suite. The combined targeted
27-case run also covers complete JSON request equivalence and rejection of
malformed/expired TON and XRP quotes.

Reproduce using the fix commit recorded in `index.json`:

```sh
swift test --build-system native --package-path Packages/OathAnkr \
  --scratch-path /tmp/oath-authority-review --jobs 4 \
  --filter PublicSigningAuthorityTests
```

For the before result, in an isolated checkout of the fix commit, restore only
`PublicSigningEVM.swift` from parent `ae5a35cec58f51bcfd6de3cd55950b47fa055a51`;
keep the added test and rerun the same command. This is an explicitly constructed
reproduction tree, not evidence claimed against a clean pinned final checkout.

App Store availability is not established. Broad package diagnostic failures
remain separately recorded in `review/TEST-TRIAGE.json`.
