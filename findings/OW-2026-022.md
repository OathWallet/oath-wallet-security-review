# OW-2026-022 — Queued session cleanup could access a released owner; store timers remained registered

Severity: **low**, SDK lifecycle availability and resource cleanup. No remotely
triggered Oath crash, fund loss or secret exposure has been demonstrated.

## Affected behavior

[HistoryService.removePendingRequest](https://github.com/devdasx/oath-wallet/blob/d13c1979398ab3dc51d9af18f5bf23821e18262f/Vendor/Reown/Sources/WalletConnectSign/Services/HistoryService.swift#L35-L39)
queued a closure with an unowned service reference. If the service was released
before execution, the closure aborted instead of deleting the topic's pending
history. Committed cleanup should finish independently of its service owner.

[SequenceStore](https://github.com/devdasx/oath-wallet/blob/d13c1979398ab3dc51d9af18f5bf23821e18262f/Vendor/Reown/Sources/WalletConnectUtils/SequenceStore.swift#L56-L60)
registered a repeating timer with a weak reference but never invalidated it at
teardown. The callback no longer had useful work, but the timer remained valid.
The store's owned scheduler resource should be released with the store.
