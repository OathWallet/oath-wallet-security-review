# OW-2026-032 — Bitcoin review could return a packet the signer could never accept

> Current audit target: [5.0.2 (104) prerelease](../review/RELEASE-5.0.2-104.md). Earlier results below retain their original tested versions and commits; they are not retroactively tests of build 104.

**Severity low.** A dApp could feed a small, validly structured Bitcoin WalletConnect signing request into the wallet's review path. The wallet could present an unusable plan and do unnecessary work expanding its funding records. There is no demonstrated unauthorized signature, disclosure or movement of funds.

**Reproduction.** Eight distinct input outpoints spend outputs of the same synthetic parent. Review checks the parent's transaction ID and adds its raw transaction to each input map. At the [regression baseline](https://github.com/devdasx/oath-wallet/blob/005a2fbf683773f3dffc51abe82f6d794271249a/Packages/OathBitcoin/Sources/OathBitcoin/BitcoinConnectPSBT.swift#L114), review accepted a resulting 509,260-byte packet. Calling the production revalidator on that returned plan threw `invalidPSBT` because the parser had a 500,000-byte limit. The serializer could also create a 500,001-byte packet. A smaller shared-parent plan passed at both revisions. The proof constructs predecessors on the host. None were broadcast.

**Repair.** [PR #44](https://github.com/devdasx/oath-wallet/pull/44) enforces the limit at three stages. Parent collection caps retained unique raw bytes. Review accounts for every parent copy, including repeated references, before decoding another parent. The encoder counts every field length, key, value and map terminator before appending it. A compact request that cannot produce a signable review packet now fails during review. The decoder bounds the encoded input before allocating its Base64 result. Packets at the documented limit retain their wire encoding.

**Scope.** The collection cap applies to retained raw funding transactions. Concurrent requests and URLSession response buffering have separate peak memory costs. The evidence does not measure peak resident memory, estimate production incident frequency or validate other dApp approval flows. The [PSBT trace](../review/BITCOIN-PSBT-REVIEW.md) describes the signing checks and other open questions.

Reproduce the packet checks with `python3 scripts/bitcoin-psbt-size.py <clean-app> --scratch .work/psbt-build --output .work/psbt`. The companion `scripts/bitcoin-parent-budget.py` exercises parent collection using an audit-owned URLProtocol fixture. Both runners execute individual host cases with network access denied.
